# FuelIXpro — İndirme Sayfası

**FuelIXpro**, Gilbarco Two Wire ve Dart Pump Interface protokollerini destekleyen,
6 pompa × 4 tabanca, 6 tank seviye izleme (magnetostrictive probe) ve RFID kimlik
doğrulama sunan akaryakıt istasyonu pompa otomasyon yazılımıdır.

> Bu depo yalnızca **kurulum paketlerini ve kullanım dokümanlarını** içerir.

## İndirme

En güncel sürüm için **[Releases](../../releases/latest)** sayfasına bakın.

| Platform | Dosya |
|---|---|
| Windows 10/11 | `FuelIXpro-Setup-<sürüm>.exe` |
| macOS (Apple Silicon) | `FuelIXpro-<sürüm>.dmg` |

### Kurulum notları
- **Windows:** Setup yönetici yetkisi istemez; kullanıcı dizinine kurar. Mevcut kurulumun
  üzerine kurulduğunda veriler ve lisans korunur.
- **macOS:** dmg'yi açıp uygulamayı Applications klasörüne sürükleyin. İlk açılışta
  Gatekeeper uyarısı çıkarsa: sağ tık → Aç.
